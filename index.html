📍 座標の割付(標定点)

点群の中の目印(標定点)をクリックして登録し、その点の既知座標(公共座標)を入力します。点群全体を正しい座標に合わせます。

iPhoneのLiDARスキャンは上下(重力)の向きが正しいので「水平回転+移動」がおすすめ。チェックを外した点は検証点になり、精度確認だけに使います。

座標の並びを直す

上から見て左右が逆(鏡写し)になっている時は、X(北)とY(東)が入れ替わっています。

✏️ 現況の作図(構造物をなぞる)

見やすくする

「段差・勾配」は縁石・擁壁・法肩の線が浮き出ます。「地面からの高さ」は建物・構造物・樹木が目立ちます。

上限を下げると屋根や木の枝が消え、壁や柱の位置が見えやすくなります。

描くもの

クリックで点を追加 → Enter・右クリックで確定。線を閉じるときは C。Shiftを押しながらで直角・一直線。描いた点の近くでは自動でくっつきます(黄色い枠)。

作図の一覧
保存・出力

等高線と一緒に出すときは「📐図面」の平面図から出力します。単位・文字コードは「📐図面」の設定を使います。作図はこのパソコンに自動で一時保存されます。

🧩 点群をつなぐ

いま表示している点群(基準)に、別の点群を追加してつなぎます。1スキャンずつ処理・座標合わせをしてからつなぐと、正確で点数も抑えられます。

追加した点群(水色)に写っている標定点をクリックし、既知座標を入力します。「📍座標」で読み込んだ既知点リスト(SIMA)からも選べます。

重なっている部分の同じ目印(杭・構造物の角など)を、① 追加した点群(水色)→ ② 基準の点群 の順にクリックします。なるべく離れた場所で3組以上とると正確です。

位置を計算するまでは、追加した点群(水色)を基準の点群の右横に仮に並べて表示しています。

重なった部分で点が二重になるのを防ぎます(全体を指定の間隔の立体格子で1点にします)。

つないだ点群

つないだ後も「↩️元に戻す」で取り消せます。つないだ点群は「💾出力」でLAS保存できます。

🔺 TIN・計画面との照合

① 現況TINを作る

点群から地形の三角網(TIN)を作ります。先に「✂️除去 → ④地表面の抽出」で草木や構造物を消しておくと、正確な地形になります。

m 以上

LandXMLは「3次元設計データ交換標準」のTIN(Surface)形式です。SiTECH 3Dでは現況地形として読み込めます。

② 計画面を読み込む

SiTECH 3D などで作った3次元設計データ(LandXML)を読み込みます。点群は「📍座標」で公共座標に合わせておいてください。

③ 計画面と比べて土量を出す

現況TINと計画面TINを細かい格子で比べます(メッシュ法)。現況が計画より上=切土、下=盛土。

📐 平面図の出力(DXF)

点群から等高線・標高点・外形線を作り、CADで読めるDXFで保存します。先に「✂️除去 → ④地表面の抽出」で草木を消しておくときれいな等高線になります。

保存するときにファイル名と保存先を選べます。

レイヤ: 主曲線 / 計曲線(5本ごと) / 等高線文字 / 標高点 / 外形線 / 標定点 / 点群 / 作図の種類ごと(道路端・側溝・建物など)
日本語が文字化けする場合は文字コードを「UTF-8」にしてください(レイヤ名が英語になります)。この設定は断面・縦断図にも使われます。
座標: 図面の横(x)=東(公共Y)、縦(y)=北(公共X)。等高線は標高を持った線です。
用紙: 選んだ縮尺と用紙で、図形が用紙の真ん中に来る位置を書き込みます(図形の座標は動かしません)。CAD側でも同じ縮尺・用紙にしてください。断面・縦断図にもこの用紙の設定を使います。
断面図・連続横断図・縦断図は「⛰️断面」で線を引いてから出力します。

❓ 使い方

🖐️
表示モード

指1本でドラッグ → 回転 / 指2本で広げる → 拡大縮小 / 指2本でスライド → 移動
(PC: 左ドラッグ=回転、ホイール=拡大、右ドラッグ=移動)

🧍
視点ボタン(画面左)

目線=現場に立って見た景色 / 真上=平面図 / 正面・横=立面図 / 斜め=全体の鳥瞰。迷ったら「目線」を押せば元に戻ります。

✂️
除去モード

範囲を囲んで削除/切り抜き、ノイズ除去、高さ除去、地表面抽出、間引き。失敗しても「↩️元に戻す」(Ctrl+Z)で戻せます(5回まで)。

📍
座標モード

標定点をクリックして既知座標を入力 →「計算する」で較差を確認 →「適用」で公共座標に合わせます。

🧩
点群をつなぐ

処理済み(座標付き)のLASはそのまま重ね、直接取ったPLYは標定点か共通点で位置を合わせてからつなぎます。1スキャンずつ処理してからつなぐのがおすすめです。

🔺
TIN・計画面

点群から現況TINを作ってLandXML(SiTECH 3D向け)で保存。設計の計画面(LandXML)を読み込むと、TIN同士の比較で土量を計算し、差をヒートマップで表示。断面図・縦断図にも計画線が入ります。

✏️
作図(現況構造物)

道路端・側溝・擁壁・建物・電柱などを点群の上からなぞって描きます。真上の平行投影で表示され、「段差・勾配を強調」の色で縁石や法肩の線が見やすくなります。Enter=確定 / C=閉じる / Shift=直角 / Ctrl+Z=元に戻す。

📐
図面(CAD出力)

「📐図面」で等高線・標高点の平面図、「⛰️断面」で線を引いて断面図・連続横断図・縦断図をDXFで出力。曲がった道路は「線の引き方」を「中心線(折れ線)」にします。

💾
出力モード

編集した点群をLAS・CSV・TXTで保存します。点密度チェックもここ。

⌨️
キーボード(PC)

Ctrl+Z=元に戻す / Enter=範囲を確定 / Esc=やめる / Delete=選んだ点を削除

📏
距離モード

点群の上を2か所タップすると、斜距離・水平距離・高低差が出ます。

⛰️
断面モード

2か所タップして線を引くと、その線に沿った断面図(横から見た形)が出ます。

🧮
土量モード

基準の高さ(計画高)より上を切土、下を盛土として計算します。範囲を囲み、切土・盛土の法面勾配(1割5分など)を指定すると、法面の土量も含めて計算します。

🔄
向きがおかしい時

⚙️設定 → 寝そべって見えたら「横倒しを起こす」、逆さまなら「上下を反転」。

💡
コツ

測定モード中でもドラッグで視点は動かせます。タップ(すぐ離す)で点を選択します。

💾 ファイル名を決めて保存

保存先はブラウザのダウンロード設定に従います。毎回保存先を選びたい場合は、ブラウザの設定で「ダウンロード前に各ファイルの保存場所を確認する」をオンにしてください。
